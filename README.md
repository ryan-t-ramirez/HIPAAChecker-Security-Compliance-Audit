# HIPAAChecker: Security & Compliance Audit

### 🛡️ Project Overview
This repository contains the documentation, testing procedures, and compliance findings for **HIPAAChecker**, a healthcare software platform. The goal of this project was to perform a Quality Assurance (QA) audit to verify adherence to **HIPAA (Health Insurance Portability and Accountability Act)** regulations.

### 📂 Contents
* **Professional Project.pdf**: The primary executive summary of the project.
* **Testing Procedure and Instruction.pdf**: Detailed breakdown of the QA methodologies used.
* **HIPAACHECKER-Pitch.pptx**: The stakeholder presentation outlining the product's security posture.
* **Progress Reports**: Weekly breakdowns of the audit timeline and remediation steps.

### 🔍 Key Findings
* Validated compliance against **45 CFR Part 160**.
* Identified and documented logic errors in patient data handling.
* Authored the official user manual and remediation protocols for the engineering team.
