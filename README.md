# HIPAAChecker: Security & Compliance Audit

### 🛡️ Project Overview
This repository contains the documentation, testing procedures, and compliance findings for **HIPAAChecker**, a healthcare software platform. The goal of this project was to perform a Quality Assurance (QA) audit to verify adherence to **HIPAA (Health Insurance Portability and Accountability Act)** regulations.

### 📂 Repository Contents
* **1_Security_Audit_Professional_Project.pdf**: The primary executive summary and full audit findings.
* **2_HIPAAChecker_Testing_Protocols.pdf**: Detailed breakdown of the QA methodologies used.
* **3_Stakeholder_Presentation_ProfessionalProject.pptx**: The executive presentation outlining the product's security posture and risk assessment.
