# HIPAAChecker: Security & Compliance Audit

### 🛡️ Project Overview
This repository contains the documentation, testing procedures, and compliance findings for **HIPAAChecker**, a healthcare software platform. The goal of this project was to perform a Quality Assurance (QA) audit to verify adherence to **HIPAA (Health Insurance Portability and Accountability Act)** regulations.

### 🛠️ Remediation & Outcomes
* **Identified Critical Logic Errors:** Found data handling flaws that could expose PHI (Protected Health Information).
* **Authored System Documentation:** Created the official user manual and remediation guides for the engineering team.
* **Verified Platform Support:** Validated security controls across mobile and web endpoints.
